# SKYFORGE — Journal de décisions

## Décision 001 — Sources de référence initiales

Les fichiers de référence initiaux du projet SKYFORGE sont les exports MO2 de Nolvus et Nefaram :
- Nolvus : modlist + plugins/load order
- Nefaram : modlist + plugins/load order

Nolvus sert de référence principale pour le socle technique, graphique, gameplay, UI, monde, villes, quêtes, combat et magie.
Nefaram sert de référence secondaire pour les systèmes SexLab, défaite, slavery, prostitution, outfits et roleplay adulte.

## Décision 002 — Démarrage alternatif

SKYFORGE utilisera Skyrim Unbound Reborn comme système de démarrage alternatif.

Alternate Perspective et ses patches issus de Nolvus seront exclus.

Raison :
Skyrim Unbound Reborn correspond mieux à l’objectif roleplay libre de SKYFORGE, permet de contrôler le statut Dragonborn, les dragons et le départ du personnage, et dispose déjà d’une logique de patching présente dans Nefaram.

Décision :
Garder Skyrim Unbound Reborn.
Différer ses patches jusqu’à l’installation des mods concernés.
