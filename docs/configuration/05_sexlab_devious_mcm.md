# Configurations SexLab / Devious / adultes

> Procédure personnelle du projet **SKYFORGE**. Aucun fichier de mod ou fichier soumis à redistribution restreinte n’est inclus dans ce dépôt.

Ce fichier documentera les réglages liés à SexLab, Devious, BaboDialogue, defeat, slavery, prostitution, systèmes adultes, MCM et fichiers de configuration associés.

---

## Décisions déjà retenues

- `SexLab 1.63` est le choix définitif pour SKYFORGE, mais le module SexLab n’est pas encore installé.
- `Devious Followers` est exclu par défaut, sauf dépendance réelle et indispensable d’un futur mod officiellement retenu.
- Les voix supplémentaires anglaises ne seront pas installées par défaut.
- SKYFORGE utilisera `BaboDialogue` en version `6.12 hotfix` plutôt que la version `5.70` utilisée par Nefaram.
- Les patches Nefaram liés à BaboDialogue ne seront pas repris automatiquement.

## Devious Followers

**Décision :**  
Exclu par défaut de SKYFORGE.

**Raison :**  
Le mod avait déjà été désactivé dans Nefaram par préférence de gameplay. Il est jugé trop structurant / intrusif pour la base SKYFORGE actuelle.

**Exception possible :**  
À reconsidérer uniquement si un futur mod officiellement retenu en dépend réellement.

**Conséquence :**  
Les patches Nefaram liés à Devious Followers, y compris les éventuels patches BaboDialogue, ne sont pas repris tant que le mod parent n’est pas installé.
