Ce fichier regroupe les ajouts audio / voix / ambiances documentés après le snapshot étape 530.

- compteur ESP + ESM non-light maintenu à 128 sur les validations indiquées ;
- aucun lancement de LOOT, DynDOLOD, BodySlide ou Pandora.

## Étape 534 — NPC Dialogue Audio Enhancer

### Objectif
Améliorer la clarté et la présence audio des voix NPC pendant les dialogues, sans ajouter de lignes, sans traduction FR à gérer, sans script et sans impact sur SexLab, animations ou Pandora.

### Référence
- Source principale : Nolvus Awakening
- Type : audio / voices / dialogues NPC
- Étape précédente validée : 533
- Snapshot MO2 de référence : étape 530 + ajouts étapes 531 et 533

### Mod installé
- NPC Dialogue Audio Enhancer

### Lien
- NPC Dialogue Audio Enhancer : https://www.nexusmods.com/skyrimspecialedition/mods/40040

### Placement MO2 réel
Bloc utilisé : `[04 - AUDIO MUSIC VOICES]`.

### Validation
Étape validée. Compteur ESP + ESM non-light inchangé : 128.
