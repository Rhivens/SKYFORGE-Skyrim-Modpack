# Décision future — Startup Save / MCM Recorder

## Objectif

Consigner une décision différée concernant la future phase de finalisation de SKYFORGE.

SKYFORGE adoptera probablement en fin de construction une logique inspirée de Nefaram autour de :

- **MCM Recorder**, pour rejouer automatiquement les réglages MCM validés ;
- une **save de démarrage propre**, créée après initialisation des systèmes ;
- une procédure documentée afin d’éviter une configuration manuelle longue à chaque nouvelle partie.

Cette logique est différée jusqu’à stabilisation complète du modpack.

## Statut

- **Décision :** retenue comme piste future.
- **Installation actuelle :** aucune.
- **Configuration actuelle :** aucune.
- **Action immédiate :** aucune.
- **Priorité actuelle :** continuer la construction et la stabilisation du socle SKYFORGE.

## Moment recommandé

La startup save ne devra pas être créée trop tôt.

Elle devra intervenir uniquement après stabilisation des gros systèmes :

- socle technique ;
- gameplay ;
- combat ;
- UI / HUD ;
- body / physics ;
- systèmes adultes futurs ;
- BodySlide final ;
- Pandora final ;
- réglages MCM combat ;
- réglages MCM UI / HUD ;
- ENB / graphismes stabilisés ;
- patches finaux ;
- LOD / DynDOLOD final.

## Point de prudence

La startup save devra être créée après l’initialisation des systèmes lourds, et non avant.

Objectif : éviter de figer dans une sauvegarde de démarrage un état incomplet, instable ou encore provisoire.

## Règle future

Avant création de la startup save finale :

1. vérifier que tous les modules majeurs sont installés ;
2. vérifier que les générateurs nécessaires ont été lancés ;
3. vérifier que les réglages MCM sont validés ;
4. vérifier que le profil est stable ;
5. documenter précisément la procédure ;
6. conserver une copie de sécurité du profil MO2 avant création de la save.

## Conclusion

Cette décision est importante pour la phase finale de SKYFORGE, mais elle ne doit pas être appliquée pendant la construction actuelle.

Elle sera reprise uniquement lorsque le modpack sera proche de son état final.
