# Ajouts personnels SKYFORGE

> Procédure personnelle du projet **SKYFORGE**. Aucun mod, archive Nexus, fichier Bethesda, fichier Creation Club, fichier SKSE, ENB ou élément soumis à redistribution restreinte n’est inclus dans ce dépôt.

---

## Objectif

Ce fichier centralise les mods et ressources que Fabien souhaite ajouter à SKYFORGE alors qu’ils ne proviennent pas directement des références principales **Nolvus** ou **Nefaram**.

Ces ajouts personnels peuvent inclure :

- tenues, armures et vêtements ;
- presets RaceMenu ;
- presets BodySlide ;
- mods SexLab supplémentaires ;
- ressources graphiques ou cosmétiques ;
- patches personnels ou conversions ;
- mods à tester, à comparer ou à abandonner.

Ce fichier ne remplace pas les étapes d’installation.  
Chaque mod personnel devra quand même être documenté dans son module thématique au moment de son installation.

---

## Règle d’identification

Tout mod ou ressource ne venant ni de Nolvus ni de Nefaram doit être marqué :

`Source : AJOUT FABIEN / SKYFORGE Custom`

ou, dans les étapes d’installation :

`Source : Ajout personnel Fabien`

---

## Statuts utilisés

| Statut | Signification |
|---|---|
| `Prévu` | Mod souhaité, pas encore testé. |
| `À tester` | Mod à installer dans une phase dédiée pour validation. |
| `À vérifier` | Mod ou version à comparer avec une autre source / version. |
| `Remplacement prévu` | Mod destiné à remplacer une version Nolvus / Nefaram. |
| `Patch potentiel` | Patch peut-être nécessaire selon les choix futurs. |
| `Version verrouillée` | Version maximale / exacte à respecter. |
| `Validé Nefaram` | Mod testé et fonctionnel dans l’ancien environnement Nefaram de Fabien, mais encore à vérifier dans SKYFORGE. |
| `Installé` | Ajout personnel installé et validé dans SKYFORGE. |
| `Abandonné` | Mod écarté après décision ou test. |

---

## Note importante

Cette liste est **non exhaustive**.  
Elle pourra être modifiée par ajouts, suppressions ou changements de statut après :

- tests de compatibilité ;
- conflits détectés ;
- doublons avec Nolvus ou Nefaram ;
- problèmes de dépendances ;
- intérêt réel du mod après essai ;
- compatibilité Skyrim SE 1.5.97 / Best of Both Worlds ;
- compatibilité CBBE / 3BA / BodySlide / RaceMenu / SexLab.

## 12. Règles d’intégration futures

Lorsqu’un ajout personnel est installé :

1. il doit être documenté dans le module thématique correspondant ;
2. sa source doit être indiquée comme `AJOUT FABIEN / SKYFORGE Custom` ;
3. son statut doit être mis à jour dans ce fichier ;
4. s’il crée une dette technique, elle doit aussi être ajoutée dans `docs/procedure/97_registre_dette_technique.md` ;
5. s’il nécessite BodySlide, RaceMenu, SLAL, FNIS / Nemesis / Pandora, SMP ou un framework SexLab, la dépendance doit être notée clairement ;
6. si le mod est abandonné après test, ne pas supprimer l’entrée : passer son statut à `Abandonné` avec une courte raison.

## 13. Points de vigilance globaux

- Vérifier la compatibilité Skyrim SE 1.5.97 / Best of Both Worlds.
- Vérifier les dépendances SKSE / DLL éventuelles.
- Vérifier les requirements RaceMenu, High Poly Head, hair packs, brows, eyes, overlays, sculpts pour les presets `.jslot`.
- Vérifier les dépendances BodySlide / CBBE / 3BA / SMP pour les tenues.
- Vérifier les conversions 3BA et les meshes Bodyslide.
- Vérifier la compatibilité avec la future génération BodySlide globale.
- Vérifier les conflits possibles avec Nefaram, Practical Defeat, Acheron, prison, slavery, prostitution, followers et captivity.
- Vérifier les versions LoversLab / Nexus / Patreon si plusieurs sources existent.
- Ne pas installer de patch ou hotfix si le mod parent n’est pas officiellement retenu.
- Vérifier les chemins de configuration utilisateurs pour les mods qui écrivent dans `Documents\My Games\Skyrim Special Edition`.
- Pour les tenues validées dans Nefaram, vérifier les doublons avec Nolvus, les conflits de fichiers, les variantes de corps inutiles et les patches éventuels avant intégration SKYFORGE.
