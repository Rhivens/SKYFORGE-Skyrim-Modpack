## Règle pour les futurs audits

Si une étape manquante est retrouvée plus tard :

1. documenter son contenu dans le fichier thématique approprié ;
2. mettre à jour ce fichier d’audit ;
3. préciser si le numéro était :
   - validé ;
   - sauté ;
   - annulé ;
   - différé ;
   - fusionné avec une autre étape ;
4. ne jamais réutiliser un numéro ancien pour une nouvelle installation sans preuve qu’il correspondait réellement à cette étape.
