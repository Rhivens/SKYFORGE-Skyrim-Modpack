# ALERTE SKYFORGE — NEFARAM 17 / migration Skyrim 1.6.1170

## Statut

Alerte technique majeure à destination de l'Intendant SKYFORGE.

NEFARAM 17 migre officiellement vers Skyrim 1.6.1170, SKSE 2.2.6 et SexLab Framework 1.66beta.

Cette migration constitue une rupture de génération par rapport à l'environnement officiel SKYFORGE.

D'après le changelog publié sur Discord pour NEFARAM 17 :

- base désormais sur Skyrim 1.6.1170 ;
- mise à jour vers SKSE 2.2.6 ;
- SexLab Framework 1.63 -> 1.66beta ;

- Open Animation Replacer modernisé vers branche 3.x ;
- ajout de Devious Curses, Penetration Physics, SLSF Reloaded, Public Whore Jail Replacement ;
- 169 mods ajoutés ;
- 84 mods retirés ;
- 293 mods mis à jour.

## Décision officielle SKYFORGE

SKYFORGE reste officiellement basé sur :

- Skyrim SE 1.5.97 Best of Both Worlds ;
- AE / Creation Club conservé ;
- SKSE pour runtime 1.5.97 ;
- MO2 portable ;
- installation progressive, testée et documentée étape par étape.

NEFARAM 17 ne doit donc plus être utilisé comme référence stricte de versions techniques pour SKYFORGE.

## Utilisation autorisée de NEFARAM 17

NEFARAM 17 peut rester utilisé comme source d'inspiration pour :

- la sélection de mods ;
- la logique de blocs ;
- les idées de gameplay ;
- les modules adultes ;
- les systèmes defeat / prison / prostitution / slavery ;
- les quêtes ;
- les followers ;
- les maisons ;
- les contenus LoversLab ;
- les suppressions de mods obsolètes ou trop lourds.

Cependant, toute reprise d'un mod depuis NEFARAM 17 devra être validée mod par mod pour SKYFORGE 1.5.97.

## Position officielle

- Nefaram actuel de Fabien : figé, conservé, aucune mise à jour Wabbajack.
- NEFARAM 17 : veille technique et inspiration seulement.
- SKYFORGE : maintien strict sur Skyrim SE 1.5.97 Best of Both Worlds.

## Note opérationnelle pour l'Intendant SKYFORGE

Lors des futurs audits ou installations, ne pas proposer automatiquement les versions issues de NEFARAM 17 si elles ciblent Skyrim 1.6.1170 / AE.

Toujours vérifier :

1. compatibilité Skyrim SE 1.5.97 ;
2. compatibilité SKSE 1.5.97 ;
3. dépendances Address Library correspondantes ;
4. présence ou absence de DLL ;
5. existence d'une version SE/1.5.97 archivée ou maintenue ;
6. impact sur SexLab, Acheron, Yamete, Devious, OAR, FSMP et MCM.

Conclusion : NEFARAM 17 est une référence moderne AE 1.6.1170, pas une base technique directe pour SKYFORGE 1.5.97.
